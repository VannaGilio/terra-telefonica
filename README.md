## Projeto Integrador Interdisciplinar 2

O projeto consiste no desenvolvimento de uma única soluçõ, integrando os conhecimentos das disciplinas cursadas ao longo do semestre.
____

## Base de dados - Terra Signal 

A **Terra Signal** é uma emopresa fictícia  do setor de telecomunicações. A base *history.csv*, disponibilizada pela **Databricks**, contém informações sobre sua carteira histórica de clientes, incluindo características individuais, serviços contratados, relacionamento, informações financeiras e históricos de cancelamento.

## Objetivo do Projeto 

### O Problema 
Como estruturar, processar, armazenar e disponibilizar de forma segura os dados da **Terra Signal**, para que possam ser utilizados em análises capazes de apoiar a compreenssãode sua carteira de clientes? 

### Objetivo Geral 
Desenvolver uma solução integrada para estruturar, processar e armazenar e analisar os dados da **Terra Signal**, utilizando a Arquitetura Medalhão e técnicas de análise exploratória, de modo a produzir informações confáveis que apoiem a compreensão de sua carteira de clientes.
